# 长文结构（公众号）

按以下骨架写作，面向手机端阅读：

1. **开头（150 字内）**：用一个具体场景或反常识结论抓住读者，直给本文要解决的问题。
2. **结论先行**：第二段给出核心观点，不要留到最后。
3. **主体 3–5 节**：每节一个小标题，每节只讲一件事，配一个例子或数据。
4. **可执行清单**：给出读者今天就能做的 3 条行动建议。
5. **结尾**：一句话总结，不诱导分享，不制造焦虑。

写作约束：
- 单段不超过 4 行；多用短句。
- 每个关键论断要有来源；没有来源就标注“个人经验”。
- 不使用“最佳/第一/100%/万能”等绝对化用语。
- 保留作者口吻，不要写成通稿。
