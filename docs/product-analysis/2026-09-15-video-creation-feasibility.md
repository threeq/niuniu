# 视频创作能力可行性分析（定稿）

> 状态：**已定稿**（issue #707，2026-09-15 完成；四轮拍板结论已全部吸收进最终方案）
> 最终方案见同目录 `2026-09-15-video-creation-one-stop-design.md`（v3.0 整合版）——本文只保留研究依据与选型结论。

## 结论（TL;DR）

**可行，且牛牛的 agent 基因恰好是这类产品的核心件。** 落地不造合成引擎、不搬代码——"编排智能长在 agent/看板里，生成能力以可装配能力模块（独立 MCP）接入，合成用本地 FFmpeg"。

## 1. 两个参考项目画像

| 维度 | ClipForge（xixihhhh） | Toonflow（HBAI-Ltd） |
|---|---|---|
| 定位 | AI 带货短视频（商品图→种草片） | 小说→剧本→分镜→AI 视频片段→成片的短剧工厂 |
| 合成引擎 | **本地 FFmpeg**（fluent-ffmpeg，`-filter_complex_script` 规避 Windows 命令行长度） | **浏览器 WebCodecs/WebAV**，服务端零渲染 |
| 模型接入 | 统一 Provider 抽象，7 平台 30+ 模型；Ollama 本地档 + Edge keyless TTS 免费档 | 可编程供应商（vm2 沙箱 + 在线 TS，五函数接口）；按模型加载提示词模板 |
| agent 入口 | **自带 MCP Server + CLI + Agent Skill** 三件套，Web 只是壳 | 三层 Agent（决策/执行/监督）+ 提示词全部文件化 Skill（画风包） |
| 质量机制 | 脚本判官团、镜头质量闸门、**坏镜单点重生成**、废片诊断单变量重投 | 分镜中间产物+人工节点精修、多候选人工选条 |
| 成本护栏 | dryRun 预览+确认、花费上限、失败不自动重试、默认 720p | 成本大头在视频模型（实测 ¥130/2min，其中模型 ¥120） |
| 许可 | **AGPL-3.0**（只可进程外集成，不可 vendor 代码） | Apache-2.0 + 商业补充（≥2 家对外分发需授权；参考设计无碍） |
| 成熟度 | 799 star，一周一版，1170+ 单测 | 15.6k star（2026-01 创建），三平台安装包 |

**两者共同验证的架构事实**：LLM 编排 + 结构化中间产物（剧本/分镜表）+ 生成模型 API（TTS/图/视频，按秒计费是成本大头）+ 一个合成导出步骤 + 人工精修回路。合成一步本地 FFmpeg 与浏览器 WebCodecs 两条路线都成立，没有"必须上 GPU 集群"的隐性门槛。

## 2. 牛牛的差口

已有：agent 编排、看板流转、场景机制、产物清单与**视频预览**（native/HLS/FLV）、env provider。缺：FFmpeg（不在系统依赖清单）、教 agent 做视频的技能/模块、三方生成服务的账号配置域。即：只缺把"视频"从排期清单里的词变成工作空间里能产出的文件的那一层。

## 3. 通道评估与裁决

| 通道 | 判定 |
|---|---|
| **A. 自研**：编排走看板子 issue + 生成能力做成可装配能力模块（独立 MCP）+ 本地 FFmpeg 合成 + vendored 技能包 | ✅ **已拍板**——与 archify/cairosvg 双先例同构，牛牛的 agent 与看板就是"编排层"，这是相对独立应用的结构性优势 |
| B. 进程外集成 clipforge（它自带 MCP/CLI/Skill 入口） | 备选：AGPL 只能进程外；功能绑电商、第二套 BYOK、外部生命周期管理。作为场景可声明的第三方 MCP 工具源留口 |
| C. 内置合成服务 / Toonflow 式画布时间轴产品 | 否决——archify 已证"重写活跃演进项目即刻过时"；WebAV 与工作空间文件模型错位；工作量以人月计 |

**许可红线**：clipforge AGPL-3.0 不搬代码；Toonflow 设计可参考、代码不搬。

## 4. 决策记录（2026-09-15，四轮）

① 方向=通道 A，目标"一站式 AI 生成视频能力"，图生视频进第一期（报价确认制）；② 本期范围=仅方案设计与可行性研究，不实现，临时文档放工作空间根目录不入产品仓库；③ 架构=三层（编排/交互/工具），成品质量为顶层目标（质量闸门体系），拓扑=R1 混合（单控制工作空间+子 agent 波内并行），实现顺序=工具层先行（P1→P2→P3），直接 P1 起步；④ 工具层细化=生成服务账号与 env_provider 分离（独立能力配置域）、能力 MCP 独立二进制可装配（配置页随模块装配）、Provider 代码级抽象、FFmpeg 为最终装配器不动摇。
